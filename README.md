# 🔐 Interface de Autenticação Responsiva

Este projeto consiste num sistema de login moderno, focado na usabilidade (UI/UX) e na criação de layouts flexíveis e modulares.

## ⚙️ Características Técnicas
- **Flexbox & CSS Grid:** Utilização combinada de sistemas de layout para alinhamento preciso de componentes.
- **Feedback Visual:** Implementação de **Pseudo-classes** e **Transições CSS3** para estados de hover, foco e validação.
- **Validação de Interface:** Foco na experiência do utilizador para garantir preenchimento intuitivo de campos.
- **Arquitetura CSS:** Organização modular para facilitar a manutenção e escalabilidade.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox, Grid, Animations)
